# Setup — Amir1ted Blue Neural Profile

This bundle is designed for the special GitHub profile repository `Amir1ted/Amir1ted`.

## Install

1. Back up your current `README.md`.
2. Copy the new `README.md`, `assets/`, and `.github/` folders into the root of `Amir1ted/Amir1ted`.
3. Commit and push to `main`.
4. Open the repository's **Actions** tab.
5. Run **Blue Contribution Snake** once manually.
6. Run **3D Profile Contributions** once manually.
7. After both workflows finish, refresh your GitHub profile. The snake and 3D graph will appear.
